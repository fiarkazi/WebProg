# WebProg
Задание по веб-программированию:
### 1. Цель работы

Создать простую веб-страницу с использованием HTML, CSS и JavaScript, продемонстрировав базовые навыки разметки страницы, оформления элементов и обработки пользовательского ввода.

### 2. Описание задания

Необходимо разработать одностраничный сайт — визитную карточку.

В качестве главного персонажа страницы можно выбрать:
- самого себя;
- вымышленного персонажа;
- героя фильма, мультфильма, игры или комикса;
- любую другую личность или персонажа на своё усмотрение.

Страница должна содержать краткую информацию о выбранном персонаже, его изображение и форму обратной связи.

### 3. Требования к HTML

1. Страница должна иметь корректную HTML-структуру.
2. Необходимо использовать не менее 10 различных HTML-тегов (например, h1, h2, p, div, img, a, ul, li, form, input, button и другие).
3. На странице обязательно должны присутствовать:
   - заголовок с именем или названием персонажа;
   - изображение персонажа;
   - текстовое описание (несколько предложений);
   - дополнительная информация на усмотрение студента;
   - форма обратной связи.

### 4. Требования к CSS

Для оформления страницы необходимо использовать CSS.

Минимальные требования:
- задать цвета фона и текста;
- настроить размеры и оформление заголовков;
- использовать отступы между элементами;
- оформить изображение;
- оформить поля формы и кнопку отправки.

Дизайн остаётся на усмотрение студента. Сложная вёрстка, адаптивность и анимации не требуются.

### 5. Требования к форме обратной связи

На странице должна присутствовать форма, содержащая следующие поля:

1. Имя — текстовое поле, обязательное для заполнения.
2. Email — поле для ввода электронной почты, обязательное для заполнения.
3. Сообщение — многострочное текстовое поле, обязательное для заполнения.
4. Кнопка «Отправить».

### 6. Требования к JavaScript

При нажатии на кнопку «Отправить» должна выполняться проверка данных формы с помощью JavaScript.

Необходимо проверить:
- что поле «Имя» не пустое;
- что поле «Email» не пустое и содержит адрес электронной почты в допустимом формате;
- что поле «Сообщение» не пустое.

Если какое-либо поле заполнено неправильно, пользователь должен увидеть сообщение об ошибке.

Если все данные корректны, необходимо вывести уведомление с помощью alert():

«Данные формы успешно проверены! Отправка на сервер пока не настроена».

Важно: фактическая отправка данных на сервер не требуется. После проверки страница не должна перезагружаться.

### 7. Технические ограничения

- Использовать только HTML, CSS и JavaScript.
- Не использовать библиотеки и фреймворки (React, Vue, Bootstrap и другие).
- Серверная часть и база данных не требуются.
- Страница должна открываться локально в браузере без установки дополнительного программного обеспечения.
- Проверка формы должна выполняться именно с помощью JavaScript, а не только встроенными средствами HTML.

### 8. Порядок сдачи работы

Исходный код проекта необходимо разместить в публичном Git-репозитории на любой удобной платформе для хранения и управления версиями кода.

Например:
- GitHub;
- GitVerse;
- SourceCraft;
- любая другая аналогичная платформа.

Рекомендуемая структура проекта:


project/
├── index.html
├── style.css
├── script.js
└── images/
    └── photo.jpg


Структура может отличаться от предложенной. Главное, чтобы в репозитории находились все файлы, необходимые для работы страницы.

Для сдачи лабораторной работы необходимо предоставить ссылку на репозиторий.

Требования к репозиторию:
- Репозиторий должен быть публичным и доступным для просмотра без авторизации.
- По ссылке преподаватель должен иметь возможность просмотреть исходный код проекта.
- В репозитории должны находиться все необходимые файлы HTML, CSS и JavaScript.

Размещать работающий сайт в интернете необязательно. Достаточно исходного кода, который можно скачать из репозитория и открыть локально в браузере.

### 9. Дополнительная информация

Содержание страницы, выбор персонажа, изображения, цветов и оформления остаются на усмотрение студента.
